# Rawchunks landing

The public site at `https://rawchunks.space`. Introduces the Studio generator, multitrack editor, instruments, voice engine, API and Market.

[Website](https://rawchunks.space) · [Launch app](https://app.rawchunks.space) · [Documentation](https://docs.rawchunks.space)

## Stack

React 19, TypeScript and Vite.

## Local development

Run from this repository:

```sh
npm ci
npm run dev
```

Build the production bundle:

```sh
npm run build
npm run preview
```
